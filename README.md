### build process
required java 21 <br><br>
on linux:
```
git clone https://github.com/Sebz102030/MoreDiodes.git
cd MoreDiodes
./gradlew build
cd build/libs
```

on windows:
```
git clone https://github.com/Sebz102030/MoreDiodes.git
cd MoreDiodes
gradlew.bat build
cd build/libs
```
